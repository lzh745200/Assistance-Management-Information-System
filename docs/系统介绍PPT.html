系统概述
System Overview
🎯

建设目标

为军队单位帮扶乡村工作提供全流程信息化管理工具，实现帮扶数据可追溯、帮扶过程可监控、帮扶成效可量化，助力乡村振兴战略落地。

🏗️

设计理念

完全离线运行，数据本地存储，零网络依赖。支持多机协同数据同步，适合网络受限的军营环境。安装包内置所有运行时，目标机器零依赖。

📱

适用平台

主要平台：Windows 10及以上版本（x64安装包）
次要平台：麒麟V10国产操作系统（ARM64 DEB包）
浏览器：Chromium内核（Electron内置）

🔐

安全特性

机器码设备绑定、JWT双Token认证、RBAC权限控制、数据范围隔离、操作审计日志、双因素认证(2FA)、AES-256加密传输、CSRF防护。

安全特性
Security Features · 军事级安全标准
🔐

JWT双Token认证

Access Token + Refresh Token轮换机制，支持Token黑名单和真正吊销，退出登录立即生效。

🖥️

机器码设备绑定

基于CPU/主板/硬盘/MAC地址生成唯一机器码，账号绑定到特定电脑，防止未授权设备登录。

👥

RBAC权限控制

6种角色（超管/管理员/经理/审批领导/普通用户/访客），页面级+操作级+数据范围级三层权限。

🔑

双因素认证(2FA)

支持TOTP动态验证码（Google Authenticator等），备用码防丢失，管理员可强制启用。

📝

操作审计日志

所有用户操作完整记录（登录/增删改查/审批等），双写数据库+文件日志，不可删除。

🔒

AES-256加密传输

数据包同步使用AES-256加密，数据库支持加密初始化，密码使用bcrypt哈希（10轮）。

🛡️

CSRF防护 + 速率限制

Double Submit Cookie模式CSRF防护，登录/注册/刷新令牌接口均有速率限制。

📊

数据范围隔离

每条数据关联organization_id，查询自动按组织过滤，跨组织访问返回403。

部署与版本
Deployment & Version

🖥️ Windows部署 x64

  • PyInstaller打包后端为assistance-backend.exe（含Python+全部依赖+SQLite）
  • electron-builder打包NSIS安装包（.exe）
  • 内置VC++ Redistributable（NSIS钩子静默安装）
  • 安装后双击桌面图标即可运行，零依赖
  • 数据库存储在%LOCALAPPDATA%\bumofu-assistance\data\

🐧 麒麟V10部署 ARM64

  • Docker交叉编译（QEMU ARM64模拟）
  • 生成.deb安装包，dpkg一键安装
  • 包含desktop桌面文件+systemd服务+polkit策略
  • 支持纯Web模式（无Electron，浏览器访问）
  • 适配飞腾/鲲鹏处理器

📊 测试规模

  • 后端测试：10000+ 用例（pytest），覆盖率≥98%
  • 前端测试：1600+ 用例（Vitest），125个测试文件
  • E2E测试：Playwright 5条关键路径冒烟测试
  • 性能测试：Locust负载测试
  • CI/CD：PR检查 + 每日全量构建 + Codecov追踪
